# 🎓 Full School System (Students - Teachers - Admin)

A comprehensive web-based platform designed to streamline academic operations. This system integrates real-time attendance tracking with efficient course management, featuring dedicated interfaces for Administrators, Teachers, and Students.

## 👥 System Roles & Features

### 1. 👑 Admin (System Administrator)
* **User Management:** Create, update, or remove profiles for students and teachers.
* **Course Administration:** Add, edit, or delete courses and define academic structures.
* **System Oversight:** Monitor overall attendance patterns and maintain database integrity.

### 2. 👨‍🏫 Teacher (Instructor)
* **Attendance Tracking:** Mark student attendance for specific sessions and subjects.
* **Course Management:** View assigned classes and manage student records within their subjects.
* **Reporting:** Generate attendance summaries for their respective classes.

### 3. 👤 Student (Learner)
* **Attendance Monitoring:** View personal attendance records and track overall performance.
* **Course Enrollment:** See details of enrolled courses and upcoming schedules.
* **Profile Management:** Access personal information and academic standing.
